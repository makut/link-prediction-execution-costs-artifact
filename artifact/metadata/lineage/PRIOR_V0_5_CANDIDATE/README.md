# Public link-prediction artifact — v0.5 candidate, not frozen

This local candidate integrates exact v0.4 public sources with the repaired
PENCILV2 public driver and the public E7/E12 numeric/path admission adapters.
It is not a published artifact or a claim that new measurements passed.
`metadata/V0_5_GATES.json` lists the actual-result and release gates. No v0.5
archive, tag, public repository, download URL or DOI has been created here.

Original v0.4 scientific sources and all206 frozen pins remain unchanged.
Only candidate documentation/registries are replaced, with their original
bytes preserved in `metadata/lineage/BASE_V0_4_*`. The root MANIFEST is a
mutable candidate inventory with explicit unfrozen status. Historical v0.4
flags and commands remain provenance; use the new public entrypoints below.

The full public quality and retained systems evidence remain separate exact
assets, referenced under `metadata/external_assets/`, without duplicated
models, scores, graphs or nested archives. The systems asset includes all
retained public raw evidence and portable offline numeric/figure commands.
The three reviewed adapters are also copied unchanged under
`tools/public_evidence/`; pass the separately extracted systems root and the
exact quality archive as their documented arguments.

For public graph acquisition/preparation and original V4/native commands,
read `README_v0_3_BASE.md` and `SYSTEMS_REPRODUCTION.md`. No full graph should
be downloaded to a laptop for these large Linux workloads.

For repaired PENCIL use `PUBLIC_PENCIL_V2_CANDIDATE.md` and, from `src/`,
`python -m artifact_public.reproduce_pencil_v2` with its required public
Citation2/input/output/coordination arguments. Default mode is plan-only.
The repaired frozen graph-only Transformers policy runs before BERT without
patching installed packages or pinned upstream code. This featureless random
frozen model control is not trained prediction quality or a SOTA result.

For E7/E12 use `work/vldb_public_fresh_adapters_v1/README.md` and
`run_public.py --experiment e7` or `e12`. These new wrappers preserve the
original scientific routines and all fixed cohorts while replacing historical
absolute-path/mtime admission with complete public23-payload numeric hashes.
They never forge an old freeze or timestamp. The26 actual public reproduction
files and independently verified closure are retained at
`metadata/evidence/fresh_friendster_v1/`: all512 E7three-case records match,
and all20,480 E12ranks/reciprocals and six NPY files are byte-identical to the
originals. This is a numerical reproduction, without a new timing comparison.
Recheck those values without graphs or models:

```sh
python -B tools/public_evidence/recheck_fresh_friendster_v1.py \
  --candidate-root /absolute/path/to/this/candidate \
  --systems-asset /absolute/path/to/lpp_public_systems_evidence_v1.tgz \
  --out /absolute/path/to/new_recheck.json
```

The new recheck changes only author-workspace paths/output arguments in the
retained original independent auditor. Its unmodified original source and the
explicit derivation record are also included.

Actual PENCIL and matched-host evidence is reserved under
`metadata/evidence/actual_*` until exact complete archives, outside receipts,
independent audits and public member selections pass. No whole mixed private
matched archive or private graph/query/case records may enter the public tree.
Missing lifecycle evidence remains unknown, including external pod removal;
packaging performs no restart, new experiment or automatic resource release.
