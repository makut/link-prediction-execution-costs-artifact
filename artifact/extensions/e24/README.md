# Reproduce the matched128 posthoc cost-regime analysis

Use ordinary Python3.10 or newer. Supply these two local raw archives:

- Friendster E20: the existing v0.5.0 public asset
  [`lpp_public_friendster_cpu_matched_v2_raw.tgz`](https://github.com/makut/link-prediction-execution-costs-artifact/releases/download/v0.5.0/lpp_public_friendster_cpu_matched_v2_raw.tgz),
  2,121,570 bytes, SHA256
  `546cad6f6b14c9f56844dc3414804e97f0dd303028532910dd74bee9d10f9374`.
- Citation2 E22: `citation2_cpu_matched_v1_20261126.tgz`, already included with
  the public E22 extension under `recorded/`, 570,654 bytes, SHA256
  `363e25fe48e11792e53b00f37eef567c9da7f766cb1af7175c89fe69f973a61f`.

Set `FR_E20_RAW` and `C2_E22_RAW` to those files, then choose a new output name:

```sh
python3 -B publicanalyze_cost_regimes.py \
  --friendster-archive "$FR_E20_RAW" \
  --citation2-archive "$C2_E22_RAW" \
  --output NEW_COST_REGIMES.json
```

Both archive arguments are required. The script uses only the standard library,
streams the selected report/geometry/selection/manifest members without tar
extraction, and checks whole archive and selected member identities. It never
opens recorded source paths, accesses a network or cluster, loads graph arrays
or models, or reruns an experiment. No author/workspace path is required.

`ADAPTER_LINEAGE.json` binds the original analysis script and proves byte-for-byte
preservation of `median3`, `ranks`, `spearman` and `analyze`. The only changes are
explicit raw-archive inputs, bounded E22 archive reading and additional E22
archive provenance. `PUBLIC_REPLAY_CHECK.json` records one actual offline replay
of both existing archives and exact equality of every dataset metric and case
with the original derived result.

This is descriptive posthoc analysis of separate Friendster128 and Citation2
128 cohorts. The fixed proxy uses `Q<=max(1,Ds)` without fitting. Cost sums reuse
the three-repeat per-case edge-construction medians; routing overhead was not
measured. No old768 timing observations are pooled, and no independent-query,
confidence-interval, trained-quality or end-to-end speedup claim is made.

## Figure and interpretation

Reproduce the paper figure from the recorded derived observations using Python
with Matplotlib (the checked render uses Python 3.12.10 and Matplotlib 3.10.3):

```sh
python3 plot_matched_cost_regimes.py \
  --input recorded/derived_cost_regimes.json --out NEW_FIGURE_DIRECTORY
```

Alternatively, pass the JSON generated by the two-archive analysis above. Its
numeric cases are identical; source provenance reflects the local raw archives.
The figure includes all 256 cases, separate graph colors and cap markers,
logarithmic axes and the fixed threshold lines. No curve or threshold is fitted.

On the matched cohorts, pair probing wins 111/128 Friendster cases and scan
wins 70/128 Citation2 cases. The rank correlations are 0.9898 and 0.9307. The
fixed rule agrees with the faster observed plan on 116/128 cases in each graph.
Its hypothetical selected-cost factors over the better constant plan are only
1.0155 and 1.0474, before unmeasured routing overhead. They are descriptive
posthoc cost summaries, not new dispatcher throughput measurements.

`recorded/INDEPENDENT_NUMERIC_PEER.json` records independent joining of selected
geometry and raw timings, node-set rehashing and arithmetic. The original
analysis source is preserved under `lineage/`; the public entry point uses only
the explicit raw-archive arguments above. Recorded author paths in provenance
are observations and are never opened by the public tools. Own code is MIT;
the original raw-source licenses and notices remain with their artifacts.
